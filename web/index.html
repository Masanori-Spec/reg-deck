WORKING NOTES

迷いやすいところを、
明示的に。

01

アドレスを推測しない

PDUは0–65535。1始まり表記は1を引きます。5桁参照はHolding 40001–49999 / Input 30001–39999のみ。記録の開始位置は常にPDUです。

02

バイトを見える形に

標準のワード内は上位バイトが先。32ビットの組合せは機器の仕様で確認します。ABCD / CDAB / BADC / DCBAを明示して、正規化したビット列を残します。

03

期待値を固定する

期待値は手入力、または基準資料から。マップ編集で自動更新されません。サンプルは架空の参照データです。自分のプロジェクトはJSONで保存してください。

04

境界を決めておく

256フィールド、64記録、各記録4096ワード、合計65536ワード、インポート2MiBまで。データの送信や自動保存はありません。読み込み後の計算はオフラインで動作します。
